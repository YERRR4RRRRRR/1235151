PLUGSY Exporter (exUE5) — stan projektu na 30.07.2026

1. Overview
-----------
- Repo: PLUGSY Exporter Python plugin for Unreal Engine 5.8(.1).
- Purpose: export current Level Sequence to FBX with UE ToolMenus, Tkinter selection dialog, progress dialog, and debug console.
- Current package structure:
  - exUE5/exporter.py          (compatibility wrapper)
  - exUE5/exporter_core.py     (core export logic, playhead save/restore, path building)
  - exUE5/spawnable_diagnostics.py (spawnable binding analysis and export warnings)
  - exUE5/ui_dialogs.py        (Tkinter export/progress UI)
  - exUE5/menu_utils.py        (shared menu helper utilities)
  - exUE5/menu.py              (menu registration and callbacks)
  - exUE5/selection_dialog.py  (binding/track selection dialog)
  - exUE5/debug_console.py     (live log buffer and console window)
  - exUE5/cleanup_menu.py      (stale menu cleanup logic)
  - exUE5/install.py           (install/uninstall wrapper)
  - exUE5/init_unreal.py       (startup hook)
  - exUE5/config.json          (machine-local config)
  - exUE5/config.example.json  (neutral sample config)

2. Verification status
----------------------
- `py_compile` passed for all `exUE5/*.py` modules.
- Package import validation passed for all `exUE5` modules in a standard Python environment.
- `exUE5.init_unreal` import logs an expected runtime failure because `unreal` is unavailable outside the editor environment.

3. Confirmed fixes
------------------
- Menu registration now uses a relative submenu `name` and avoids duplicate `MainFrame.MainMenu.MainFrame.MainMenu.PLUGSY_Exporter` entries.
- `collect_all_tracks()` tries multiple sequence methods (`get_tracks`, `get_master_tracks`, `get_all_tracks`) to support UE 5.8.1.
- Spawnable detection is implemented in `spawnable_diagnostics.py` with `_get_spawnable_binding_ids()` and `_warn_about_spawnable_export_bug()`.
- Cyclic import between `exporter.py` / `exporter_core.py` / `spawnable_diagnostics.py` has been addressed.

4. Confirmed open issues
------------------------
1. `exporter_core.py` still has potential playhead API mismatch:
   - `_save_sequence_playhead()` tries `get_current_time()` then `get_current_frame()`.
   - `_restore_sequence_playhead()` tries `set_current_time()` then `set_current_frame()`.
   - This is the known issue reported as "playhead does not return after an emergency save" and requires exact UE API signature verification on 5.8.1.
2. `ui_dialogs.py` still contains UI label duplication and spacing issues in the export dialog.
3. `selection_dialog.py` currently builds binding labels from `get_display_name_fn(binding)` and appends spawnable markers, but the reported bug "spawnable_names get ID instead of name" is not yet fully confirmed by the current code path.
4. `install.py` / `menu.py` still contain misleading or incomplete messaging around `enable_menu_integration`.
5. `config.json` still contains a machine-specific `default_output_folder` path (`E:/@9SUKUYOMI/PLUGSY_DO_3D/WORKFLOW9/TU`).
6. Camera export issue is unresolved:
   - Current code logs spawnable export diagnostics when a sequence has spawnable bindings.
   - If `_warn_about_spawnable_export_bug()` emits warnings, the expected fix is manual "Convert to Possessable" in Sequencer.
   - If no warning appears, the bug is likely different (e.g. camera missing from `bindings`, missing transform track, or a separate export path problem).
7. Audit cleanup still pending:
   - duplicate helper definitions remain in `menu.py` despite `menu_utils.py` existing,
   - duplicate removal helper logic remains in `cleanup_menu.py`,
   - `install.py` may have stale local imports,
   - `debug_console.py` imports `ttk` only inside `DebugConsoleWindow` and may be fine, but the audit still flagged UI import cleanup.
